# 拼图模板

`templates.json` 是 2026-10-15 从 Pixlr 拼图页公开请求的 `https://pixlr.com/grid/index.json` 保存的 160 条布局定义，字段与顺序保持原样。只包含几何布局，不含官网照片或品牌资源。编号由应用按数组顺序生成。

渲染器为本项目独立实现，支持矩形、多边形、整体与单元形状裁剪、圆角和照片覆盖裁剪。轮播采用本项目参数化布局生成器，支持等宽、交替宽窄、斜切、两行、三行与主图布局；并非 Pixlr 轮播代码的逐行复制。

入口 `/photo-collage` 独立懒加载。编辑器模板面板通过新标签打开拼图，避免丢失当前编辑上下文。

拼图支持两种编辑器导入方式：

- **可编辑槽位导入**：原始照片转为持久 data URL，连同模板、间距、圆角和归一化缩放/取景状态，通过内存 handoff 导入。每张照片是独立 Fabric image，以 `kidstoryCollageId` 关联锁定的布局背景，组成逻辑槽位组。这样可直接选中、拖动与替换照片，不必先解组。导入适配编辑器当前画布；画布 `sizeChange` 时统一重新计算几何。矩形、多边形与整体/单元形状使用同一 Canvas/SVG 路径构造逻辑。右侧拼图面板可调整布局（保持槽位数）、间距、边框、圆角和照片缩放；左侧模板面板可直接添加全部 160 种空白槽位布局。
- **合成图片导入**：沿用 pending-image 通道，作为一张普通合成图片进入编辑器；轮播结果为整张长图。

布局元数据位于背景的 `kidstoryCollage`，每张照片的 `kidstoryCollagePhoto` 保存 zoom/panX/panY。上述属性和槽位框信息纳入编辑器 JSON、历史及本地草稿。更新时替换元数据对象，避免改写旧历史快照；重新载入及撤销/重做后恢复裁剪和布局。照片替换走专用分支，保留不规则裁剪而不是退回矩形。

交互：上传或拖入图片，选择相同照片数的模板，拖动平移，滚轮/双指缩放，双击重置。勾选“拖动交换照片”后拖到目标格，或拖动照片列表/使用前移按钮调整顺序。单张导出 PNG，轮播按每页宽 1080 像素切片为 PNG 并打包 ZIP。只有照片数与槽位数一致时允许导出，防止静默遗漏图片。
